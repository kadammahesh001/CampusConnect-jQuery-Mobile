              About

              CampusConnect

              A mobile student information portal for Data Science students, built as Assignment 6 (jQuery Mobile) for the Full Stack Web Technology Laboratory.

              Objective

              Build a simple mobile website with jQuery Mobile using single-document multi-page navigation, dynamic content, form validation and LocalStorage.

              Technology stack

              HTML5, CSS3, JavaScript, jQuery 1.11.1, jQuery Mobile 1.4.5, LocalStorage. These are legacy versions, no longer actively maintained.

              Developer

              Mahesh Kadam, B.Tech Data Science, MIT Academy of Engineering, Alandi, Pune. Academic year 2026.

              Academic project; not an official institutional product.
